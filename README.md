# ⚖️ دستیار کارشناس رسمی — نسخه آزمایشی

توسعه داده شده توسط **صادق مرادزاده**  
**مرکز کارشناسان رسمی دادگستری لرستان**

## بخش‌ها
- 💰 محاسبه حق‌الزحمه — مستقل از پرونده
- 📁 پرونده‌ها
  - 📅 مهلت‌ها و تقویم
  - 📷 بازدید و مستندات
  - 📄 اسکن اسناد و PDF
  - 📑 فهرست اسناد
  - 📝 نظریه کارشناسی

اطلاعات پرونده‌ها با SQLite روی خود دستگاه ذخیره می‌شود و با خروج از برنامه از بین نمی‌رود.

## ساخت APK
از GitHub Actions با Workflow `Build Android APK` استفاده کنید.
